# Crossformer 133 输入、27 输出实验

当前训练入口强制校验150+5+60点窗口，复用上级 `window_contract.py`。历史30秒空档结果保留，不能用于10秒实验；旧数据需按[迁移说明](../README.md)重建。

该目录为独立实验，不修改 `latency_fusion_133` 或更早的训练脚本。

- 输入：旧 128 + 新 5，共 133 字段。
- 输出：历史筛选得到的 22 个连续字段和 5 个布尔字段。
- 窗口：历史 300 秒，空档 10 秒，预测 120 秒。
- 调参：设备 01/02/03 三折留一设备。
- 设备 04 不进入调参；由于目标名单曾参考设备 04 历史结果，它不能作为干净的最终外部测试。

模型包装现有 Crossformer：骨干接收 133 通道，输出后只选择目标字段对应的 27 个通道参与损失和对外输出。非目标字段仍作为历史输入协变量。

执行顺序：

1. `tune_latency_133_to_27.py`：在设备 01/02/03 三折留一上调参。
2. `confirm_latency_133_to_27.py`：用更大样本复核最优参数。
3. `train_final_latency_133_to_27.py`：使用确认后的轮数在设备 01/02/03 上训练最终模型。

最终脚本默认不评估设备 04。可选评估结果会明确标记为探索性结果，而不是干净的外部测试。
